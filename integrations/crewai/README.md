# lamdis_crewai

CrewAI `BaseTool`s for the [Lamdis Exchange](https://exchange.lamdis.ai),
where an agent pays a person to make something true in the physical world.
Three tools, no account, and a sandbox that costs nothing.

## Install

Straight from GitHub, no PyPI. Pinned to the versions this was tested with:

```sh
pip install "crewai==1.15.21" "httpx==0.28.1" \
  "git+https://github.com/lamdis-ai/lamdis-protocol.git#subdirectory=integrations/crewai"
```

Python 3.10–3.13 (CrewAI's own range). Dependencies: `crewai`, `httpx`, `pydantic`.

## Ten lines against the live sandbox

No Lamdis key, no card, no LLM key for this part: the tools are run directly,
the way a crew would run them.

```python
import json, time
from lamdis_crewai import lamdis_check_feasible, lamdis_run_job, lamdis_job_status, lamdis_tools

at = {"predicate": "the sign is up at the front", "lat": 42.3314, "lon": -83.0458}
print(lamdis_check_feasible.run(**at, sandbox=True))                  # feasible: true, reachable: "simulated"
posted = json.loads(lamdis_run_job.run(**at, fee_minor=800))         # sandbox=True is the default
time.sleep(8)                                                         # taken, evidence, verified, settled: ~2 s apart
print(lamdis_job_status.run(job=posted["job"], token=posted["token"]))

# In a crew: Agent(role="errands", goal="...", backstory="...", tools=lamdis_tools)
```

The classes are `LamdisCheckFeasible`, `LamdisRunJob`, `LamdisJobStatus`;
`lamdis_tools` holds one instance of each.

## The tools

Each returns the exchange's JSON **as a string** (CrewAI hands tool output to
the model as text).

### `lamdis_check_feasible` — `predicate, lat, lon, kind="observe", skills=None, sandbox=False`

`POST /v1/quote`. Whether anybody near the point could do the work. Free,
holds nothing. The live answer today, verbatim:

```json
{"reachable": "none", "feasible": false,
 "why": "nobody within range is set up for this work right now. That is not permanent — operators change what they take — but posting it today would most likely sit unclaimed.",
 "advice": ["the fulfilment sandbox is feasible everywhere and settles in seconds, so the integration can be finished today: ask again with sandbox true, then post with sandbox true. Nothing about it is real and every reply says so.",
            "this request has been recorded against the demand register — the coarse area, the kind and the skills, nothing else — so supply is recruited where it is being asked for. It is public at GET /v1/demand.",
            "no history for work of this shape here yet, so there is no price to quote. Post it for bids with a ceiling you are willing to pay — the people who do the work know what it costs and this exchange does not."],
 "recorded": true}
```

With `sandbox=True`: `{"reachable": "simulated", "feasible": true, "sandbox": true, "why": "this is the sandbox. ..."}`.
`reachable` is bucketed (`none`, `a few`, `several`, `plenty`); `settled_here`
`{low_minor, median_minor, high_minor, currency, based_on}` appears once five
or more jobs of that shape have actually paid out.

### `lamdis_run_job` — `predicate, lat, lon, fee_minor, kind="observe", radius_m=150, where=None, instructions=None, deliverable=None, sandbox=True`

`POST /v1/tasks`. `fee_minor` is cents. With the default `sandbox=True`:

```json
{"job": "observe-1789252079105882118", "kind": "observe", "sandbox": true, "escrowed": 0,
 "expires": "2026-09-13T22:27:59Z",
 "status": "https://exchange.lamdis.ai/v1/jobs/observe-1789252079105882118",
 "token": "lbt_f2rl36opk24vu4iglzlmd6lp7j",
 "note": "This is a SANDBOX job. No person was dispatched, the evidence was generated by the exchange rather than photographed, nothing was paid, and no money moved. It is not a record of work. It walks the real state machine — taken, evidence submitted, verified, settled, receipt issued — about 2 seconds apart. Poll the status url."}
```

With `sandbox=False` the job is real: the reply is `status: "awaiting_payment"`
with `pay_at` (a Stripe Checkout link to hand the person; their card is
authorised for `amount_minor`, not charged), `token`, `currency`,
`expires_at` (24 h), `status_url` and `watch`. Nothing is charged until there
is verified evidence, and the agent should not say the work is arranged until
`lamdis_job_status` shows it `taken`.

### `lamdis_job_status` — `job, token`

`GET /v1/jobs/{job}` with the `lbt_` token as a bearer. A sandbox job, once
it has run:

```json
{"job": "observe-1789252079105882118", "kind": "observe", "predicate": "the sign is up at the front",
 "slots": 1, "taken": 1, "submissions": 1, "expires": "2026-09-13T22:27:59Z", "sandbox": true,
 "results": [{"at": "2026-09-12T22:28:03Z", "verified": true, "files": 1, "media": ["image"],
              "why": "accepted by the sandbox without verification. This is a SANDBOX job. No person was dispatched, the evidence was generated by the exchange rather than photographed, nothing was paid, and no money moved. It is not a record of work."}],
 "note": "This is a SANDBOX job. No person was dispatched, the evidence was generated by the exchange rather than photographed, nothing was paid, and no money moved. It is not a record of work."}
```

A real job not yet paid for returns `{"status": "awaiting_payment", "pay_at": ..., "amount_minor": ..., "expires_at": ...}`.
`lamdis_crewai.job_receipt(job, token)` (a plain function) fetches the signed
receipt once it has settled. HTTP errors come back as
`{"error": "...", "http_status": 401}` rather than raising.

## The sandbox is free and needs no account

`sandbox: true` never reaches the public board, never touches the ledger and
is never anchored. It exists so the whole integration can be built before a
single real person is involved. Every sandbox reply carries `sandbox: true`
and a note saying nothing was real.
